`scripts/install.sh` installs mngr on Python 3.12 (`uv tool install imbue-mngr --python 3.12`). Where Python 3.15 was the newest interpreter, such as a Mac with Homebrew's `python3`, uv built the tool on 3.15 and failed compiling google-re2 (pulled in by cel-python), which has no 3.15 wheel yet, so nothing was installed. The pin can go once google-re2 ships 3.15 wheels (google/re2#647).
